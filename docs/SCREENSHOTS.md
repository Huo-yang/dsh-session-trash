# README 截图清单

[返回 README](../README.md)

两份 README 使用以下同一组实际界面截图，并分别提供对应语言的说明。

| 文件名 | 页面 | 展示内容 |
| --- | --- | --- |
| `session-menu.png` | 会话列表中打开一条演示会话的「…」菜单 | 包含「移入回收站」「彻底删除」，尽量同时露出侧边栏回收站按钮 |
| `trash-panel.png` | 打开回收站面板 | 使用 1–3 条无隐私的演示会话，显示恢复、逐条删除、清空与设置入口 |
| `settings.png` | 原生设置 → 会话删除 | 尽量完整显示暂存、保留天数、确认和自动清理设置 |

截图使用演示内容，不包含真实会话正文、私人目录、账户信息或带 token 的地址栏。后续界面发生用户可见变化时，应重新检查这三张截图是否仍与当前版本一致。
